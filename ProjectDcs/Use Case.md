## 1. Use Cases

### UC-FA-TE-001: Manage Suppliers

**Actor**: Admin

**Steps**:
1. Navigate to Travel Expense
2. View supplier list
3. Add/edit supplier
4. Set preference order

---

### UC-FA-TE-002: Create Trip

**Actor**: Employee

**Steps**:
1. Navigate to My Trips
2. Click New Trip
3. Enter dates/destination
4. Submit for approval

---

### UC-FA-TE-003: Submit Expenses

**Actor**: Employee

**Steps**:
1. Open trip
2. Click Add Expense
3. Enter date, category, amount
4. Upload receipt
5. Submit expense report
